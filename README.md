# 🚌 Last Marshrutka

![Last Marshrutka Logo](https://via.placeholder.com/800x300)

## 📌 О проекте

**Last Marshrutka** — это симулятор жизни, созданный на игровом движке **Unity**.

Игроку предстоит погрузиться в атмосферу повседневной жизни, исследовать окружающий мир, передвигаться по городу и взаимодействовать с различными объектами.

Главная идея проекта — создать реалистичный мир с ощущением настоящей жизни.
